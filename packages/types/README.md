# @next/types

Shared TypeScript contracts for wallet accounts and balances, onboarding, user roles, portfolio results, risk checks, quotes, and execution responses. `src/index.ts` also exports the runtime `USER_ROLES` tuple used to derive the `UserRole` union.

The package is private to this npm workspace and exposes its source entry through the package export map. It does not contain API implementations or validate runtime network responses by itself.
